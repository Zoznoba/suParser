      не работает (опирается на ФИО / дату рождения). Проверить, проходит ли вход работодателя в `SuperJobWebParser`
      (`SUPERJOB_LOGIN/PASSWORD`), и видны ли ФИО на текущем тарифе. Долгосрочно — перейти на официальный API (ТЗ).
- [ ] **Прод-окружение.** Сейчас фронт — dev-сервер Vite. Нужен прод-compose: сборка фронта + nginx/Caddy с TLS,
      `COOKIE_SECURE=true`, закрыть `/docs` и `/openapi.json`, Postgres/Redis не публиковать наружу.
- [ ] **Безопасность входа.** Ограничение попыток логина (rate limit по логину и IP), проверка `Origin` у WebSocket `/api/ws`.
- [ ] **Резервные копии БД** (pg_dump по расписанию + проверенное восстановление) — статусы и комментарии HR нельзя потерять.

## P1 — заметные баги и расхождения с ТЗ

- [ ] **Fallback вместо «Без имени».** Пока нет ФИО — заголовком должность (или «Кандидат · город · возраст»),
      чтобы анкеты в ленте различались. `FeedPage.tsx` (CandidateRow), `CandidatePage.tsx`, `Duplicates.tsx`.
- [ ] **«К ленте» сбрасывает фильтры и страницу** (`?source=…&offset=50` → `/`). Возвращаться через `navigate(-1)`,
      если пришли из ленты, иначе — на `/`. `CandidatePage.tsx`.
- [ ] **Статус и свой комментарий видны только через WebSocket.** При переподключении нажатие «ничего не делает».
      Обновлять кэш в `onSuccess` (`useSetStatus`, `useAddComment`, `useEditComment`, `useDeleteComment`); `handleEvent`
      уже защищён от дублей по id.
- [ ] **Поиск в ленте только по ФИО и должности.** ТЗ — «по ключевым словам»: искать ещё по навыкам, опыту,
      «О себе» (`resume` JSONB; для скорости — `tsvector` + GIN). `services/candidates.py::list_candidates`.
- [ ] **Хранение неактуальных анкет.** ТЗ: «остаётся в базе, пока актуальна» — сейчас хранятся вечно.
      Удалять через N дней (`STALE_PURGE_DAYS`) неактуальные анкеты без статуса и без комментариев. `services/stale.py`.
- [ ] **Объединённая коллегой карточка → «Анкета не найдена».** По событию `candidate.merged` перекидывать
      на `into`; на странице «не найдена» — ссылка «К ленте». `handleEvent.ts`, `CandidatePage.tsx`.
- [ ] **LinkedIn: согласовать с заказчиком отход от ТЗ** (Apify вместо отдельного аккаунта, 1 страница ≈ 25 профилей в сутки).
